## README

**Задание 1** — Открыть файл в режиме записи, проверить успешность открытия и закрыть файл.

**Задание 2** — Записать символы в файл через putc, затем прочитать их посимвольно через getc и вывести на экран.

**Задание 3** — Записать строки в файл через fputs, затем прочитать их через fgets и вывести на экран.

**Задание 4** — Записать числа и строки в файл через fprintf, затем прочитать их через fscanf и вывести на экран.

**Задание 5** — Считать строку с клавиатуры через fgets, записать её в файл и вывести содержимое файла на экран.

**Задание 6** — Создать массив целых чисел, записать его в бинарный файл через fwrite, прочитать через fread и вывести данные.

**Задание 7** — Создать структуру Person, записать её в бинарный файл, прочитать обратно и вывести данные.

**Задание 8** — Создать массив структур Person, записать его в бинарный файл, прочитать обратно и вывести все элементы.

**Задание 9** — Открыть файл, переместиться к заданной позиции через fseek, считать данные и вывести результат.

**Задание 10** — Открыть файл, определить его размер через fseek и ftell, вывести размер.

**Задание 11** — Читать файл до конца, проверить достижение конца через feof и наличие ошибок через ferror.

**Задание 12** — Ввод данных о людях с клавиатуры, запись массива структур в бинарный файл через fwrite, чтение всех записей через fread и вывод на экран с проверкой открытия файла и обязательным закрытием.

**Вопросы:**
1. Файл в языке C — это поток байтов, связанный с внешним устройством или диском, доступ к которому осуществляется через стандартные функции ввода-вывода.

2. FILE* — это указатель на структуру, которая хранит информацию о файле (позицию чтения/записи, буфер, флаги состояния и дескриптор).

3. Режимы открытия файла: "r" (чтение), "w" (запись с перезаписью), "a" (добавление в конец), "r+" (чтение и запись), "w+" (чтение и запись с перезаписью), "a+" (чтение и добавление).

4. Текстовый файл хранит данные как символы (с преобразованием перевода строки), а бинарный — как последовательность байтов в том виде, в котором они лежат в памяти.

5. putc записывает один символ в файл, getc читает один символ из файла.

6. fputs записывает строку в файл (без добавления \n), fgets читает строку из файла до \n или конца файла.

7. fprintf форматированно записывает данные в файл (как printf), fscanf форматированно читает данные из файла (как scanf).

8. fwrite записывает блок байт (массив структур) в бинарный файл, fread читает блок байт из бинарного файла.

9. fseek перемещает указатель позиции в файле на заданное смещение, ftell возвращает текущую позицию указателя.

10. feof проверяет, достигнут ли конец файла, ferror проверяет, произошла ли ошибка при работе с файлом.

11. Закрывать файл важно, чтобы сохранить данные из буфера на диск, освободить ресурсы операционной системы и избежать потери данных.
