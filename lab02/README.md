## Ответы на вопросы

**Как объявить структуру в языке C?**
```c
struct Student {
    char name[50];
    int age;
    float grade;
};
```

**Что такое вложенные структуры и зачем они нужны?**
Это структура внутри другой структуры; нужны для группировки логически связанных данных (например, дата рождения внутри человека).

**Как передать структуру в функцию?**
Можно передать по значению (`func(struct Student s)`) или по указателю (`func(struct Student *s)`).

**Можно ли создавать массивы структур?**
Да, можно: `struct Student group[30];`

**Как обратиться к элементу массива структур?**
Через индекс и точку: `group[i].name` или через указатель: `ptr->name`

**Можно ли использовать enum внутри структуры?**
Да, можно: `enum Course { FIRST, SECOND }; struct Student { enum Course course; };`

**Можно ли сравнивать структуры оператором ==?**
Нет, нельзя. Нужно сравнивать каждое поле по отдельности.
